# Quitify

Quitify is a cross-platform smoking-cessation app built with Expo and React Native. Its NestJS API is maintained in the sibling `backend-smoking/` directory.

## Documentation

Start with the [engineering docs](../docs/README.md):

- [Project overview and architecture](../docs/overview.md)
- [Local development and configuration](../docs/development.md)
- [REST and realtime API reference](../docs/api.md)
- [Data model and operations](../docs/data-and-operations.md)

## Quick start

```bash
npm install
npm run go       # Expo Go
# npm run dev    # development build
```

For backend setup, environment configuration, native build requirements, and service integration notes, see [Local development](../docs/development.md).
